# Student Scores Array Manager

This is a C++ student project that allows users to enter, display, search, sort, and analyze student scores. The program also generates a report file with the final results.

## Features

- Enter and validate student scores
- Display all scores
- Calculate total, average, minimum, and maximum score
- Search for a specific score using linear search
- Sort scores in ascending order using selection sort
- Write a final report to an output file

## Concepts Used

- Arrays
- Functions
- Loops
- Input validation
- Selection sort
- Linear search
- File output
- Formatted output with `iomanip`
